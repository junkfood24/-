# 课题 7 · 任务窃取调度

本仓库 `chy_task_stealing` 分支保存《内存键值存储引擎中的轻量级任务调度优化》中“任务窃取调度”部分的交付物。

## 入口

- [专题报告](课题7_任务窃取/任务窃取调度_课题7.docx)（PDF 同目录）
- [代码文档](课题7_任务窃取/任务窃取调度_代码文档.docx)（PDF 同目录）
- [项目说明与复现步骤](课题7_任务窃取/README.md)
- [数据集测试报告](课题7_任务窃取/dataset_test/KV数据集_任务窃取测试报告.docx)

## 内容

- `code/`：Chase-Lev 双端队列 C++17 实现、20 线程微基准、离散事件仿真器、绘图脚本。
- `results/`：主实验、阈值扫描、亲和实验的 JSON，以及 C++ 3 轮原始日志与环境记录。
- `fig/`：报告插图。
- `dataset_test/`：课程基准数据集上的 A5/Chase-Lev 对比、结果 CSV 与 `steal_cl.patch`。
- `verify_numbers.py`：交叉检查报告表 13–16 与 JSON/日志的一致性。

## 快速验证

```bash
cd 课题7_任务窃取
python verify_numbers.py
```

仿真与微基准的完整命令见项目 README。C++ 绝对数值受机器和后台负载影响，报告采用 3 轮中位数。
